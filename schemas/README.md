# Schemas

Diretório reservado aos contratos de dados utilizados pelo pipeline.

## Planejamento

O desafio exige:

- registrar o formato das mensagens no Schema Registry;
- validar a compatibilidade do contrato;
- demonstrar uma evolução de campo;
- registrar evidência do teste.

Os schemas concretos serão adicionados depois que o formato efetivamente utilizado pelo CDC for validado no ambiente.
