# Evidências de execução

As evidências desta pasta serão adicionadas durante a execução do pipeline.

## Checklist

- [ ] Fundação: cluster e identidades
- [ ] Contrato: Schema Registry
- [ ] Evolução do schema
- [ ] CDC: INSERT
- [ ] CDC: UPDATE
- [ ] CDC: DELETE
- [ ] Flink SQL: processamento
- [ ] Enriquecimento
- [ ] Regra de fraude
- [ ] Consumer
- [ ] Métricas
- [ ] Acesso
- [ ] Custo

## Regra

Toda evidência deve corresponder a uma execução real. Não serão utilizados resultados simulados como evidência do pipeline.
